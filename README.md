# AgentClear

AgentClear is an outcome-verification and settlement layer for AI-agent commerce on 0G. It is being built to bind structured task agreements to escrow, evidence-backed verification, settlement or refund, and transaction-backed agent reputation.

The repository is currently in active development. The authoritative product and engineering contract is [`AGENTS.md`](./AGENTS.md); runnable setup and verified deployment instructions will be expanded as each real integration lands.
